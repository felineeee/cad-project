# FreeCAD 3D Modeling Series (27 Parts)

A comprehensive CAD portfolio documenting a multi-part modeling progression—from fundamental sketch-based models to complex geometry—created using FreeCAD.

---

## Project Overview

* **Software:** FreeCAD
* **Goal:** Master parametric design workflows, constraint-based 2D sketching, datum geometry, and feature tree management.
* **Key Skills:** Extrusions, revolves, sweeps, lofts, parametric variables, pattern arrays, and 3D component drafting.
